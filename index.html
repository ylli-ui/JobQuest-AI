Host FREE on GitHub Pages in 5 Minutes

Teachers can easily host this interactive web application for free so students can access it on iPads, Chromebooks, or smartphones:

1

Create GitHub Account & Repository

Go to github.com, sign in, click "New Repository", name it p5-ai-career, set to Public, and click Create.

2

Upload index.html

Click "uploading an existing file", drag and drop this index.html file, and click the green "Commit changes" button.

3

Enable GitHub Pages

In your repo, click Settings → Pages (on left sidebar). Under Branch, select main and folder / (root), then click Save.

4

Get Your Live URL

Wait ~1 minute. Refresh the page to see your live URL: https://your-username.github.io/p5-ai-career/.

5

Share with P.5 Students

Copy the URL or convert it into a QR code for students to scan on their school tablets!
